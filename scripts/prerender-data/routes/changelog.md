# Changelog

The changelog is the wiki's running history, pulled straight from its GitHub commit log: every page edit, data update, and site change, grouped by week with the contributor who made it credited by name and avatar.

It's the quickest answer to "did anything change since I last checked?" - useful after a game update, when stat tables and guides get corrected in bursts, and you want to know which pages moved.

Because the wiki is a public repository, this history is complete and permanent; nothing edits the record. If you'd like your own name in it, [contributing](/meta/contributing) starts with editing any page.
