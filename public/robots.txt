# robots.txt for Slayer Legend Wiki
#
# One rule set for every crawler. Google's parser applies only the single
# most specific User-agent group to each crawler and never merges it with
# the "*" group, so a dedicated "User-agent: Googlebot" block would replace
# these rules for Google rather than add to them. Keep it to "*".
#
# Application screens (search, profiles, editor, history, 404 ...) are kept
# out of search results with <meta name="robots" content="noindex"> on the
# page itself, not with Disallow: a crawler can only honour noindex on a
# URL it is allowed to fetch, and Google's guidance is explicit that
# robots.txt is not the tool for keeping pages out of the index.

User-agent: *
Allow: /
Disallow: /api/
