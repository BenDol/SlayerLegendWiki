# <span class="text-gray-900 dark:text-gray-100">Class Overview</span>
This content is unlocked at stage 120 and level 250, granting additional bonuses to ATK and HP. There are 20 available classes, with additional secret classes unlocked through awakenings. Classes can be obtained through summoning using<img src="/images/content/goods/Goods_Diamond.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 30px; height: 30px; margin: -5px 0 0 0;" data-inline="true" />**Diamonds** or <img src="/images/content/goods/Goods_SummonSlayerClass.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 20px; height: 20px; margin: -5px 0 0 0;" data-inline="true" /> **Class Tickets**.<img src="https://raw.githubusercontent.com/BenDol/SlayerLegendCDN/main/user-content/images/characters/2026/01/03a1af75f975429d999cd9a7fd926b71.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 30px; height: 30px; margin: -2px 0 0 0;" data-inline="true" />**<span class="text-red-600 dark:text-red-400">Blast (Grade 20)</span>** cannot be summoned and requires five<img src="https://raw.githubusercontent.com/BenDol/SlayerLegendCDN/main/user-content/images/characters/2026/01/e1ab16b3c70841f4819b10070bef9df2.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 30px; height: 30px; margin: -2px 0 0 0;" data-inline="true" />**<span class="text-red-600 dark:text-red-400">Dark Rain (Grade 19)</span>** to unlock. A pity system is unlocked at summon level 10 that guarantees a<img src="https://raw.githubusercontent.com/BenDol/SlayerLegendCDN/main/user-content/images/characters/2026/01/e1ab16b3c70841f4819b10070bef9df2.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 30px; height: 30px; margin: -2px 0 0 0;" data-inline="true" />**<span class="text-red-600 dark:text-red-400">Dark Rain (Grade 19)</span>** after 3000 summons which amounts to<img src="/images/content/goods/Goods_Diamond.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 30px; height: 30px; margin: -5px 0 0 0;" data-inline="true" />**450,000**. Classes can also be obtained by combining five of the same grade to upgrade to the next higher grade.
