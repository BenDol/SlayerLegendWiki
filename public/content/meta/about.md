# About This Wiki

The Slayer Legend Wiki is a community-maintained reference and guide site for **Slayer Legend: Idle RPG** (슬레이어 키우기), GEAR2's idle action RPG for Android and iOS. The game runs deep and explains almost none of it - promotion stat gains, engraving mechanics, soul weapon souls, what actually deserves your gold in the first week. Players kept re-answering the same questions in chat, over and over. This site is where those answers get written down once, properly, and kept current.

## Who runs it

Active players. The people who write and review these pages play the game, and the numbers here were checked in-game before publishing - not lifted from a store listing or paraphrased from somewhere else. Where the game hides a mechanic, we test it; where the community has already worked something out, we verify it against our own accounts and the discussion in the [community Discord](https://discord.gg/slayerlegendsna2) before it lands on a page.

The wiki itself is open source. Every page is a plain markdown file in a [public GitHub repository](https://github.com/BenDol/SlayerLegendWiki), and the complete history of every edit is public and permanent. There is no hidden CMS and no anonymous editorial layer - you can see exactly who changed what, and when.

## How editing and review work

Anyone can propose a change: fix a typo, correct a number, add a whole page. Sign in with GitHub and hit **Edit** on any page, or open a pull request against the repository directly.

Nothing goes live unreviewed. Proposed edits become pull requests that a maintainer reads before merging, automated checks scan every submission for unsafe HTML and script injection, and anonymous submissions pass through abusive-content screening on top of that. It's a wiki, but not a free-for-all - the review step is what keeps the drop tables accurate and the vandalism out.

## What's different about this site

Three things, mainly.

**Interactive tools.** The [Skill Builder](/skill-builder), [Spirit Builder](/spirit-builder), [Familiar Builder](/familiar-builder), [Soul Weapon Engraving planner](/soul-weapon-engraving) and [Battle Loadouts](/battle-loadouts) let you plan and share complete setups instead of just reading about them.

**Curated data.** The tools and reference pages run on the same maintained data files - all 46 skills, 81 soul weapons, the full 2,000-stage progression, every promotion with its recommended level. One source, so a correction in one place fixes every page and tool that uses it.

**Tested guidance.** Progression advice here comes from playing, not from restating tooltips. When a guide tells you to prioritise ATK or hold your resources for a specific upgrade, that's because someone did it both ways. Longer community guides carry their author's name - Andy's progression guide, for example - so you know whose experience you're reading.

## Keeping up with game updates

Slayer Legend updates regularly, and numbers move. When a patch lands, affected pages get rechecked against the new build, and the Discord is quick to flag anything that no longer matches what players see in-game. Content publishes straight from GitHub, so a correction goes live in minutes rather than waiting on a release cycle - and each page's history shows exactly when it last changed.
