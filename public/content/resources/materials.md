# <span class="text-gray-900 dark:text-gray-100">The Material Economy</span>

Beyond [gold](/resources/gold) and diamonds, Slayer Legend runs a whole shadow economy of materials - each one bound to a specific system, each one a potential bottleneck. The pattern worth noticing before the catalog: almost every material below arrives automatically as you play (drops, idle rewards, dailies), which means material shortages are almost never solved by "farming harder" - they're solved by fixing the *rate*: pushing stages, claiming dailies, and pointing your daily-limited entries at the right dungeon.

# <span class="text-gray-900 dark:text-gray-100">Upgrade Materials</span>

<img src="/images/content/goods/EnchantCube 1_1.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 30px; height: 30px; margin: -2px 0 0 0;" data-inline="true" />**Enhance Cubes** - the workhorse. Levels [weapons and accessories](/equipment/enhancement), your [class](/character/class), and feeds [spirit](/spirits) upgrades. Sources: stage drops, idle rewards (cube income holds up well offline - overnight idling is a legitimate cube strategy), and the **Closed Mine** dungeon. Perpetually scarce; there is no point in your account's life where cubes feel plentiful.

<img src="/images/content/goods/Goods_AllStone.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 30px; height: 30px; margin: -2px 0 0 0;" data-inline="true" />**Attribute Stones** - element-typed (<img src="/images/content/goods/Goods_FireStone.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 24px; height: 24px; margin: -2px 0 0 0;" data-inline="true" />Fire,<img src="/images/content/goods/Goods_WaterStone.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 24px; height: 24px; margin: -2px 0 0 0;" data-inline="true" />Water,<img src="/images/content/goods/Goods_WindStone.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 24px; height: 24px; margin: -2px 0 0 0;" data-inline="true" />Wind,<img src="/images/content/goods/Goods_EarthStone.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 24px; height: 24px; margin: -2px 0 0 0;" data-inline="true" />Earth). Feed [companion](/companions/enhancement) skills and their level-1500 passives - a pipeline measured in millions. Sources: stage play, idle rewards, starter packs, events.

<img src="/images/content/goods/Goods_Emerald.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 30px; height: 30px; margin: -2px 0 0 0;" data-inline="true" />**Emeralds** - companion passives and [spirit](/spirits) equip slots (15,000 for all three). Earned from companion advancement battles, which makes them the choke point of two systems at once.

# <span class="text-gray-900 dark:text-gray-100">Soul Materials</span>

<img src="/images/content/goods/Goods_SoulWhite.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 26px; height: 26px; margin: -2px 0 0 0;" data-inline="true" /><img src="/images/content/goods/Goods_SoulGreen.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 26px; height: 26px; margin: -2px 0 0 0;" data-inline="true" /><img src="/images/content/goods/Goods_SoulRed.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 26px; height: 26px; margin: -2px 0 0 0;" data-inline="true" /><img src="/images/content/goods/Goods_SoulBlue.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 26px; height: 26px; margin: -2px 0 0 0;" data-inline="true" />**Souls (White, Green, Red, Blue)** - the [soul weapon](/equipment/soul-weapons) crafting currency. Colored souls come from deeper-stage monsters; white souls flow from everywhere including offline idle. Disassembling a soul weapon refunds a portion.

<img src="/images/content/goods/Goods_ChaosSoul.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 26px; height: 26px; margin: -2px 0 0 0;" data-inline="true" />**Chaos Souls** - reroll soul weapon engraving pieces into new shapes and rarities. Earned through soul weapon progression; spend near grid completion, not as a slot machine.

# <span class="text-gray-900 dark:text-gray-100">Entry & Roll Currencies</span>

<img src="/images/content/goods/Goods_Wing.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 26px; height: 26px; margin: -2px 0 0 0;" data-inline="true" />**Glow Feathers** - dungeon entries (Closed Mine, Training Cave). Ten per day from login and daily quests, with no farmable source - the definitive use-it-or-lose-it material. <img src="/images/content/goods/Goods_Dice_1.png" alt="" class="inline-image" style="display: inline-block; vertical-align: middle;width: 26px; height: 26px; margin: -2px 0 0 0;" data-inline="true" />**Dice** - roll [Slayer promotion abilities](/character/stats) and [companion promotion options](/companions/promotion-option); save toward Ether's 40,000-dice max-roll unlock.
